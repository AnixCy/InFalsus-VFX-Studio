# Perspective Cells

以上方远点为中心的光线、径向形变与快速不规则三角骨架。完整绘制背景，不在 BG 内仿制轨道或前景倒三角的遮挡。该模板是参考外观后的程序化实现，不是原作品源码。

## 组成

1. 构图坐标的 Y=0 在上，Y=1 在下。Focus 默认为 `(0.5, 0.18)`；金线、波动、软显露与推进场共享远点。
2. 金线沿纵深投影，远端收束，近端逐渐展开；弯曲随深度增长，避免变成在画面中心旋转的平行曲线。
3. 三角骨架采用噪声扰动的错列顶点与三角连接。对线段距离场做阈值/色阶，产生有面积的实体肋；不是均匀三角线框，也不是直接使用 Voronoi 蜂窝边界。
4. 根据边缘距离构造倒角法线、细亮边与少量风格化底图反射。反射复用输入图像，不是物理环境光追。
5. 按累计 Travel 推进，远端使用投影像素尺寸与雾淡出；角度坐标周期闭合，抗锯齿不依赖跳变的 atan2 导数。

## 文件

- `Effect.shader`：算法与自动发现的 Properties。
- `effect.json`：资源入口与目标。使用独立地址 `custom/perspective-cells`，保留旧模板缓存。
- `sequence.json`：36 秒可编辑编排输入，生成新工程；不覆盖已有人工编辑。

新建源码工程后用这里的 Shader 与描述替换模板，编译与生成步骤见[自定义工作流](../../docs/vfx/CUSTOM_EFFECTS.md)。编排旁边应有 `Source/` 与 `background.png`，或填明确路径。实际工程文件由共享事务与编辑器 codec 生成。

## 主要参数

| 组 | 控制 |
| --- | --- |
| Focus | 上方远点 X/Y，显示坐标，不与纹理 UV 混用 |
| Strands | 亮度、颜色、宽度、曲率、独立摆动相位 |
| Wave | 位移幅度、空间频率、传播相位 |
| Cell Structure | 可见度、颜色、累计路程、纵深密度、实体肋宽、顶点不规则程度 |
| Material | 对输入底图的风格化反射量 |
| Transition | 往远端收拢及软显露半径 |

0–20 秒是光线/波动，20–25 秒转场，25–32 秒推进，32–36 秒恢复。独立预览没有轨道遮挡，显示的背景范围会比实际游玩更完整；动态观感与最终相似度由用户验收。当前仍是编辑器模板，未导出游戏 addon。
