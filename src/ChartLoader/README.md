# 随包谱面加载组件

来源：MagicNeko 的 InFalsusChartLoader v0.2.2，MIT；由已有本地 `0.2.2-compat2` 源码快照迁入，版权和完整许可保留于 LICENSE。来源哈希见 ORIGIN.json。

本项目用于“一次安装运行时、曲包放入 Charts”的配套组件，不替换原游戏二进制。保留既有暂停冲突修复和只读会话快照；两种 Loader 分别构建，不能混装。新增 SPC2 路径仅对已核对的社区游戏二进制启用，不将 SPC2 当作官方支持。

谱面资源及曲绘不进入此源码目录。发行包随附 MIT 许可与来源说明；游戏生成的互操作程序集由所选 Loader 提供，不分发开发机缓存。
