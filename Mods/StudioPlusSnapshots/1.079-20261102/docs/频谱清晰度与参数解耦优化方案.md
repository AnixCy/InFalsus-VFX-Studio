# 频谱清晰度与参数解耦优化方案

本方案依据当前代码及最近两次说明整理。状态：本次只完成开发源码中频谱自带抗锯齿删除，并构建独立候选材质；不安装、不修改制谱器副本、不打包。其余条目仅为方案，尚未实装。最终视觉效果由用户实际验收。

## 1. 已完成：移除频谱自带抗锯齿

- 删除PixelIntensity的ddx/ddy覆盖计算、单元边缘四点混合和4×4平均。
- 保留Point纹理，通过Cell做一次最近单元采样；不改成双线性，也不替换为另一套自定义滤波。
- 保留频率轴、镜像、颜色、当前透明度曲线、UV时间映射、队列2905和地面判定裁切。
- 不改当前分析窗和Hop；因此源码里“输出档位带动窗口变长”的问题还在，后续按第二节处理。
- 删除的是独立频谱shader自己的采样平滑。全局SMAA/Bloom保留用户原设置。直接采样在远处可能更容易闪烁，先以清楚颗粒为优先，不擅自把抗锯齿加回。

## 2. 拟实施：将输出频点与时间窗口真正解耦

### 原因

目前WindowSize(rate,bins)直接根据输出列数选择窗口。48kHz下64–512列使用512点/10.67ms，1024列使用1024点/21.33ms，2048列使用2048点/42.67ms。调高输出时，一行混合的时间跨度也增长，产生更长时间扩散；同时2048列更容易触发现已删除的多点平均。两者叠加导致“越调高越糊”。

### 参数和行为

- 保留现有“FFT采样数”六档64/128/256/512/1024/2048、默认256，其含义严格为输出列数。
- 新增独立的“分析时间窗 / Analysis window”，建议提供10/20/40ms三档；新配置默认20ms，作为时间和频率细节的中间选择。以48kHz为例，对应实际512/1024/2048点，即10.67/21.33/42.67ms；界面同时说明实际时长。其他采样率取最接近目标时长的2次幂窗口，避免简单向上取整造成时长突然翻倍。
- 已有配置首次迁移时，按第一首加载音频的采样率，保留原有效窗口；例如当前2048输出、48kHz对应42.67ms，不偷偷切成新默认。随后用户可以独立选择20ms等档位比较效果。迁移不改变当前画面时间响应。
- 输出列数不再参与分析窗口计算。固定时间窗下切换256→512→1024→2048，只重新汇总输出，不扩大时间跨度。
- 保持当前Hop：48kHz为128点/2.67ms；输出列数变化不影响时间行间隔。整个频段使用同一窗口，避免再次出现低频单独更长的拖尾。
- 基础层和精细层使用同一分析窗口和同一时间坐标，仅输出列数不同，防止后台升级精度时频谱形状突然改变。

### 必须说明的限制

固定窗口后增加输出列数不会凭空增加真实频率信息。短窗利于时间变化，长窗利于分开相邻频率；不能承诺两者同时无限提高。若需要提升真实频率分辨能力，用户应明确调整独立时间窗，并看到实际时长变化。上一回复“直接加长各档窗口”的方案不作为默认修复执行，避免再次自动增加拖尾。

## 3. 拟实施：保留强信号层次，避免不透明度过早饱和

### 原因

现有alpha=opacity*smoothstep(0.10,0.72,e)，e达到0.72便满覆盖，强信号之间透明度没有区别，邻近强峰容易看成连成一片。

### 参数

- 保留暖色调、0–255不透明度滑条、0.10以下透明的弱信号裁切。
- 改为单调平滑曲线，参考控制点：(0.10,0)、(0.40,0.48)、(0.72,0.90)、(1.00,1.00)。保留现版中段可读性，但直到满强度才到完全覆盖，不在0.72形成平台。
- 使用单调插值约束，禁止过冲，仍乘用户不透明度；不做跨时间行平均，不用锐化制造假细节，也不默认提高Bloom。
- 此项与分析窗修改分开记录，便于分辨“信号真正分开”与“仅对比度增强”。

## 4. 拟实施：缓存与显示的一致性

- 延续现有磁盘缓存、有限并行、完整视野切换、播放方向预取及热开关复用。
- 原始缓存已有音频标识、窗口点数和Hop，可在这些条件相同的前提下复用；仅改变输出列数时禁止重算FFT或读取整首音频。
- CPU输出和GPU纹理当前主要按bins/page识别，新增时间窗后必须把窗口点数、Hop纳入层标识；否则相同bins下可能误用另一个窗口的旧纹理。
- 修改时间窗时保留旧层完整显示，只有新窗口的整个当前视野就绪后才整片替换；显示数据仍按各自的正确音频时间映射，不挪用旧时间段。
- 原始计算格式不变则不为了显示shader变化强制清空有效缓存。全局抗锯齿、旧波形、轨道、相机和谱面文件均不调整。

## 5. 实施顺序与必要验收

1. 本次已先删除频谱自定义抗锯齿；副本保持未变。
2. 后续先做参数解耦和缓存层标识，再单独做透明度曲线；不同时引入额外滤波或大范围美术改动。
3. 固定同一时间窗：同一短促信号在六档输出下，时间方向的幅度包络宽度应一致；比较合计能量包络，而非只看某一输出列的亮度，以免频带重采样影响测量。
4. 固定输出档位：改变10/20/40ms窗口，明确观察时间拖尾和相邻纯音分辨能力的取舍，不把某一个维度的改善当作整体清晰度提升。
5. 必要运行检查只覆盖编译、缓存命中、档位切换、分段连续、地面裁切和镜像/透明度；不再以大批隔离测试代替用户视觉评价。
6. 用户在相同曲目、时间、视速、相机、分辨率下对比：近处颗粒边界、远处闪烁、强峰间隙、随输出档位是否又出现额外拖尾。对参考图的最终清晰度由用户验收，不声称从截图得知Arc内部算法。
