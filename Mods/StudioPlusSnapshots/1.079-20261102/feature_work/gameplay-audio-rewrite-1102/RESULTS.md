## 与方案的实现对应

使用常开的 FMOD DSP 生成器输出音乐和音效，按统一 StartFrame 对音乐逐采样开门，代替为音乐另建暂停 Sound 通道后调用 setDelay；未来采样脉冲验证其起播准确性。这样音乐和音效直接共用一次混音回调，也避免两条输出路径的起点偏差。

编辑期间的 Unity StudioTransport 仅被游玩所有权适配，退出恢复；没有更改底层编辑工程源码。运行库为标准 FMOD Core API 的本地副本，不依赖本体私有 ifapp 桥。运行库与版权说明已纳入 distribution.json 明确清单，后续打包会包含依赖。
