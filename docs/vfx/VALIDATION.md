## 构建经验

独立 Shader 工程必须保留 `com.unity.modules.assetbundle`。缺少它时可能生成只有 Shader、没有 AssetBundle 容器对象的文件；运行时会给出具有误导性的版本不兼容错误。本次已在同版本编辑器和运行时确认该原因，不能只根据错误文本归因于 Unity 版本。

Unity 构建退出码与返回的 Bundle 清单不足以证明 Shader 有效。构建脚本还检查 `ShaderUtil.ShaderHasError`、实际重新加载生成 Bundle，并验证指定 Shader 入口。运行端仍需 GPU 检查。
