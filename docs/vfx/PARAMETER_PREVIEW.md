# 参数预览入口

当前版本 0.7.5 将参数编辑放在独立演出视图中，已支持关键帧、常用缓动与效果材质选择。完整步骤见 [演出时间轴与关键帧](TIMELINE.md)。

使用测试副本中的 Start-VFX.bat 启动，右上“演出视图”进入，左上“制谱视图”返回。界面复用宿主的扁平组件，演出数据和输入草稿独立保存。

工程使用 .vfx.json，音频/图片按本地路径引用。关闭或切换工程时只显示一个非阻塞未保存确认；保存取消或失败保持当前内容。原安装和谱面文件不变。

预览画面上方可切换 2K（2560×1440）、1080p（1920×1080）、720p（1280×720），默认 2K。选择自动保存，重启后恢复；不改变窗口大小、工程、导出或游戏内渲染。播放计时前的有限预热同样使用所选尺寸。

效果库卡片显示用途简述，悬停可读完整说明；选中效果后，检查器显示作用范围与实现提示，所选参数旁显示含义。未经确认的动态分支和辅助贴图依赖会单独说明；任意自定义 Shader 以其源码为准。[效果知识卡](reference/index.md)可按目标观感或参数名检索。

已支持编译效果导入与可编辑源码模板；背景图片在单独“背景”栏。最小游戏 addon 导出范围见 [ADDONS.md](ADDONS.md)，验证范围见 [VALIDATION.md](VALIDATION.md)。

## 尚未进入界面的底层能力

音频频段驱动、磁盘分析缓存和多参数烘焙已有独立基础设施，但当前没有“音频驱动”按钮或实时绑定控件。已生成的音频 demo 只展示烘焙后的普通曲线；修改其独立 recipe 不会自动更新工程。使用范围见 [音频驱动手册](AUDIO_REACTIVE.md)。

本次基础设施更新没有替换 0.7.5 安装或改变视觉效果。用户暂时无法验收时，现有工程可以继续使用；新的 UI、画面和实际游戏表现保留待验收。已知缺口与接入顺序见 [基础设施状态手册](INFRASTRUCTURE.md)。
