# 参数预览入口

当前编辑器版本 0.11.0 将参数编辑放在独立演出视图中，已支持关键帧、常用缓动与效果材质选择。完整步骤见 [演出时间轴与关键帧](TIMELINE.md)。

使用测试副本中的 Start-VFX.bat 启动，右上“演出视图”进入，左上“制谱视图”返回。界面复用宿主的扁平组件，演出数据和输入草稿独立保存。

制谱视图右上“异象背景：关/开”只控制观看。先在演出视图打开或编辑演出，再返回制谱并开启；背景及其效果跟随谱面播放、暂停和定位，不需要同时编辑两条时间轴。关闭立即恢复原背景；切到演出视图时隐藏制谱背景显示，返回后恢复开关状态。

该开关默认关闭，作为用户偏好与预览分辨率一起保存，不进入工程或曲包。它只把演出背景画面放在谱面后方，不改变 note、轨道/UI 透明度、相机或快捷键；不应用到视频导出。暂停且进度未变时复用画面，关闭释放预览画布；资源出错时回退默认背景。

工程使用 .vfx.json，音频/图片按本地路径引用。关闭或切换工程时只显示一个非阻塞未保存确认；保存取消或失败保持当前内容。原安装和谱面文件不变。

背景栏分别设置主图与“Bright 亮图”。选择亮图后，用效果库 Bright 的强度/关键帧控制两图混合；不使用该纹理槽的材质不受影响。“恢复默认亮图”保留动画并恢复当前材质自带贴图，更换主图保留亮图。亮图支持 PNG/JPEG、宽高不超过 4096 像素、16 MiB，保存和另存记录其路径；旧工程没有此字段时沿用默认亮图。

完整曲包或独立 addon 会复制实际使用的亮图并记录相对路径和校验值，玩家端不依赖谱师的原文件路径。该包要求 0.11.0 玩家端，旧版明确拒绝；亮图未被使用时不会附带它或提高运行要求。预览不新增渲染 Pass，制谱背景观看也使用同一配置。

预览画面上方可切换 2K（2560×1440）、1080p（1920×1080）、720p（1280×720），默认 2K。选择自动保存，重启后恢复；不改变窗口大小、工程、导出或游戏内渲染。播放计时前的有限预热同样使用所选尺寸。

效果库卡片显示用途简述，悬停可读完整说明；选中效果后，检查器显示作用范围与实现提示，所选参数旁显示含义。未经确认的动态分支和辅助贴图依赖会单独说明；任意自定义 Shader 以其源码为准。[效果知识卡](reference/index.md)可按目标观感或参数名检索。

已支持编译效果导入与可编辑源码模板；背景图片在单独“背景”栏。“导出曲包”读取已保存的 Studio 歌曲工程或可游玩曲包，输出带歌曲和演出的完整 ZIP，玩家解压 Charts 即可；详见 [CHART_PACKAGES.md](CHART_PACKAGES.md)。演出导出支持范围见 [ADDONS.md](ADDONS.md)，验证范围见 [VALIDATION.md](VALIDATION.md)。

自定义页“新建背景…”生成可用于背景单次绘制的 Shader；“新建后处理…”保留屏幕效果模板。背景源码成功预览后，可经通用材质路径构建游戏目标并随曲导出，不需要为新效果另写导出器；首次构建可能需选择 Unity 6000.3.9f1，后续复用缓存。详见 [背景材质导出](BACKGROUND_MATERIAL_EXPORT.md)。

效果库搜索“透明度”可加入轨道、分数、曲名资料、通关状态或判定文字控件，直接调节 0–1 不透明度或打帧。加入后显示简化轨道/UI 参照，游戏 addon 绑定真实对象；范围和兼容性见 [透明度说明](SCENE_OPACITY.md)。

## 尚未进入界面的底层能力

音频频段驱动、磁盘分析缓存和多参数烘焙已有独立基础设施，但当前没有“音频驱动”按钮或实时绑定控件。已生成的音频 demo 只展示烘焙后的普通曲线；修改其独立 recipe 不会自动更新工程。使用范围见 [音频驱动手册](AUDIO_REACTIVE.md)。

音频驱动和资源搬迁仍是独立基础设施；0.8.0 的透明度界面不代表这些功能已经接入。新的 UI、画面和实际游戏表现保留待验收。已知缺口与接入顺序见 [基础设施状态手册](INFRASTRUCTURE.md)。

资源搬迁与 recipe 来源保存现有独立 `.vfxwork.json` 容器，供开发者接入；当前没有新的“打包工程”菜单。该容器需携带整个资源目录，不能在现有 Studio 中作为 `.vfx.json` 直接打开。格式和验证见 [创作工程手册](CREATOR_WORKSPACE.md)。
