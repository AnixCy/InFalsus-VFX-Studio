# 参数编辑与实时预览

当前原型在 Studio+ 场景中增加一个背景平面和参数面板，使用共享演出核心求值。运行不需要启动游戏。

## 测试方式

使用生成副本中的 `Start-VFX.bat` 启动。该入口将测试用编辑器配置放在副本的 `UserData` 下，保留原安装。构建及副本生成见[开发说明](DEVELOPMENT.md)。

1. 在 Studio+ 中使用原有方式加载本地音频或谱面。
2. 右上角“演出参数”面板可移动、收起；可使用内置图案，也可选择本地 PNG/JPEG。
3. 拖动滑杆实时预览。数值框支持直接输入，回车提交，Esc 取消。一次拖动形成一条参数撤销记录。
4. 使用 Studio+ 原有播放和定位功能。Shader 时间跟随谱面显示时刻；暂停定格，定位立即重算。
5. 面板提供撤销、重做、恢复默认、保存、另存为和打开工程。

## 参数与工程

可调参数包括亮度、RGB 颜色、UV 位移强度、空间频率、时间频率、水平与垂直偏移、内置图案混合。滑杆范围是建议值，数值框可输入范围以外的有限数值。

工程为独立 `.vfx.json` 文件，包含格式版本、共享创作工程和背景图片路径，不修改 SPC。图片按原路径引用，移动或分享工程时需另行保持图片路径可用；不复制音频。图片限 PNG/JPEG、32 MiB、单边 8192 像素及约 3200 万像素。

参数修改支持撤销；图片替换本身暂未进入撤销栈。恢复默认只重置参数。切换工程或退出时提示未保存内容，修改不会自动写盘。保存检查外部文件修改并采用可靠替换；另存到不属于当前工程的已存在文件会被拒绝，应选择新文件名。

## 当前边界

- 只编辑内置材质的常量参数；核心已有关键帧能力，界面尚未暴露。不接受其他材质或带关键帧的工程。
- 当前没有自定义 Shader/AssetBundle 导入、游戏资源包导出或游戏内 Mod 安装。
- 已运行验证的测试基线是 Studio+ 1.0.7 build1030。1.079 源码接口已对照，完整主插件尚未重建验收。
- 适配器预留视频导出时钟并排除临时参数，但本次未进行完整视频导出、音频试听或性能基准测试。
- 视觉、实际鼠标键盘操作与已有谱面编辑工作流由人工验收；自动检查范围见[验证说明](VALIDATION.md)。
