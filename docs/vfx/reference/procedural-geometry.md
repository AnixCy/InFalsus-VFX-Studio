# 程序结构与材质塑形知识卡

用于选择实现手段，不规定作品风格。以下模板来自实际制作、GPU 数值检查与参考对照，不据画面断言原作品使用了某个节点或算法。

## 建模思路如何进入平面 Shader

先确定大形与空间关系，再选几何场，再分出材质层：

`投影坐标 → 顶点/细胞结构 → 边缘距离 → 色阶控制实体面积 → 倒角/亮边 → 反射与雾`

“网格”不等于细线图案。实体面宽、交汇方式、分叉、暗洞面积、近远尺度与运动方向，往往比额外噪声更影响辨识。参数变化再复杂，也无法把选错的基础结构自动修正成目标。

## Voronoi 与三角结构的选择

[Blender Voronoi 手册](https://docs.blender.org/manual/en/3.5/render/shader_nodes/textures/voronoi.html)区分 F1、F2 与 Distance to Edge；[Color Ramp](https://docs.blender.org/manual/en/4.0/render/shader_nodes/converter/color_ramp.html)把输入数值映射为颜色，也能形成遮罩。

- 想要不规则细胞、三向交汇的肋架，可用边缘距离加色阶，再另做倒角与发光。
- 想要三角洞与三角连接，应构造三角拓扑，不能假定 Voronoi 边界会成为三角网格。当前 [Perspective Cells](../../../templates/perspective-cells/README.md)采用噪声扰动的三角点阵；不是精确 Delaunay 求解，也不是 Blender 节点代码移植。
- 调细胞密度与调实体宽度是两件事。粗边包围黑洞的网络，需要有面积的实体肋与窄亮边；只增加细线亮度通常仍是线框观感。
- 反射、倒角和裂纹属于材质层，应服务于已确定的形体；不要把“加噪声”当作替代建模结构的办法。

## 投影、遮挡与运动

- 构图远点、纹理采样坐标和前景遮挡分开。当前宿主的输入 UV 与显示 Y 方向不同；模板显式转换后才计算构图。不要只看参数标签就判定远点已经移到上方。
- 判断画面中的暗区来自哪一层。轨道或前景形状造成的遮挡，不应无依据地烘进 BG；游戏自然遮挡与独立 BG 预览会有不同的可见范围。
- 运动用累计路程控制。对投影坐标中的 `depth + Travel` 求值，向前推进会让结构由远及近展开；直接把绝对时间乘一个突变速度会造成相位跳变。
- 周期角度、空间噪声和边缘扰动都要在接缝处一致；只让主图案重复不够。atan2 的坐标跳变不能直接当作纹理占用像素的导数，否则可能产生横向断带。

## 验证边界

结构与关键位置可用少量帧检查；速度、缓动和闪烁不能只凭几张静帧宣布完成。Shader 支持、GPU 输出变化、回跳与保存正确，也不等于审美或原作相似度已经通过。

实际实现见 [Shader](../../../templates/perspective-cells/Effect.shader)。性能按目标分辨率实测；一个 Pass 仍可能有较多数学计算。上述手段只是可选参考，作者可采用其他更适合的结构。
