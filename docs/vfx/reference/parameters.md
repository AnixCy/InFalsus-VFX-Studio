# 参数速查

仅用于已知内置实现；任意自定义 Shader 的同名参数不自动继承这些语义。

| 参数 | 含义 |
| --- | --- |
| `_BaseColor` | RGB 乘色：白色保留原色；大于 1 可增加 HDR 亮度。Alpha 是否有效取决于具体 Shader。 |
| `_Tint` | 底图 RGB 乘色；白色保留原色。 |
| `_Brightness` | 对 RGB 乘亮度倍数，1 保持原亮度。 |
| `_Exposure` | 曝光档位；乘数为 2 的该值次幂，+1 约为亮度翻倍。 |
| `_Contrast` | 围绕 0.18 调整对比，1 为中性。 |
| `_Saturation` | 0 为灰度，1 为原饱和度；更高会加强色差。 |
| `_Zoom` | 围绕画面中心缩放，1 为中性；大于 1 放大。 |
| `_Rotation` | 围绕中心旋转，单位为弧度；正负值控制相反方向。 |
| `_Chroma` | 红、蓝取样沿径向分开；强度使用 UV 比例。 |
| `_Ripple` | 径向 UV 位移幅度，0 为中性。 |
| `_RippleFrequency` | 径向波纹的疏密。 |
| `_RippleSpeed` | 波动相位随秒变化的速度。 |
| `_Scanline` | 扫描线造成的明暗衰减强度。 |
| `_Noise` | 颗粒噪声幅度；暂停后按同一绝对时间保持一致。 |
| `_PixelSize` | 采样色块相对源纹理像素的大小；1 为中性。 |
| `_Vignette` | 径向外围压暗强度。 |
| `_Fade` | 0 保留画面，1 压到黑色；输出不透明。 |
| `_Wipe` | 控制圆形可见范围收缩；0 为未遮罩状态。 |
| `_Ring` | 紫色环带的叠加强度。 |
| `_RingRadius` | 中心到亮环的半径，使用当前 Shader 的 UV 尺度。 |
| `_RingWidth` | 环带厚度。 |
| `_OffsetX` | 底图横向取样偏移，使用 UV 比例。 |
| `_OffsetY` | 底图纵向取样偏移，使用 UV 比例。 |
| `_Distortion` | 通用底图的正弦 UV 位移强度。 |
| `_Frequency` | 通用底图图案和位移的空间频率。 |
| `_Speed` | 时间相位推进速度；具体尺度由当前 Shader 决定。 |
| `_PatternMix` | 0 取背景图，1 取内置程序图案，中间值混合。 |
| `_FeedbackRotation` | 同帧嵌套变换的旋转角，单位弧度；正负可反向，通常与 Nested Scale 配合。 |
| `_HMoveSeed` | 改变横移扰动布局；它不是位移幅度。 |
| `_RippleBeat` | 该底图的波纹状态/相位控制，不能直接等同于项目 BPM。 |
| `_VerticalCorruptionPosition` | 纵向损坏影响区域的位置，使用当前材质坐标。 |
| `_VignetteColor` | 原始组的边缘/暗角色彩乘数；HDR 值可能提亮边缘，不能按通用暗角强度解释。 |
| `_BlockGlitchAmount` | 分块故障取样的强度。 |
| `_ChromaZoomAmount` | 缩放型颜色通道错位强度；具体空间响应随材质组而异。 |
| `_GlitchAmount` | 数字故障分支强度。 |
| `_WarpAmount` | UV 扭曲分支强度。 |
| `_DropKickAmount` | 该预设的短促冲击分支；具体动态尚未单独验收。 |
| `_ScanlineAmount` | 信号扫描线强度。 |
| `_BlurGlitch` | 模糊故障分支强度；不是通用模糊半径。 |
| `_WarpZoomAmount` | 联动变形与缩放的强度。 |
| `_HnoiseAmount` | 后处理的水平噪声扰动强度。 |
| `_ChaosAmount` | 不规则图案/坐标变形分支强度。 |
| `_ChaosPhase` | 改变 Chaos 的程序状态；不是通用秒数或拍数。 |
| `_ChaosKick` | Chaos 的冲击项。 |
| `_MalfunctionAmount` | 信号失常分支强度。 |
| `_Color` | 程序图案的 RGB 颜色；透明度是否参与取决于 Shader。 |
| `_Intensity` | 该程序化效果的叠加强度。 |
| `_Center` | UV 变换中心；XY 为归一化图像坐标。 |
| `_EphemeralAmount` | 连续流场把直线牵动成柔软弯曲。 变形来自随绝对时间变化的连续 UV 场；适合缓慢流动、拉伸和回收。 |
| `_FeedbackAmount` | 让图像形成层层嵌套的缩放与旋转。 在同一帧反复变换 UV，配合 Rotation 可反向后再复原。 此实现不读取上一帧，不需要历史帧纹理。 |
| `_SlashDisplaceAmount` | 把底图沿清楚的切片边界错开。 适合硬边撕裂、斜向切割和短促错位。 |
| `_StaticNoiseAmount` | 以噪声增加底图的不稳定质感。 调用底图材质的 Static Noise 分支；可用短包络快速收回。 |
| `_RushAmount` | 让底图产生朝向中心的径向流动感。 作用于取样坐标；空间延伸感也取决于原图的透视线索。 |
| `_CellAmount` | 引入单元格图案和局部遮罩变化。 效果依赖材质中的 Cell 图案或取样路径。 |
| `_AuraAmount` | 驱动底图 Aura 的局部扰动分支。 该组使用分段坐标、时间量化与多次取样组织变化。 尚未单独验收完整动态，不承诺固定的光晕轮廓。 |
| `_HMoveAmount` | 让底图出现分段的横向错位。 强度控制错位幅度，Seed 改变分段扰动的布局。 |
| `_ImpactAmount` | 给底图加入短促形变和冲击变化。 适合用快起、慢收的强度曲线做击点。 不同组的 Impact 不是逐像素相同的效果。 |
| `_TriDisplaceAmount` | 用三角分区组织底图的错位。 相邻分区可产生有边界的几何撕裂，区别于连续流场。 |
| `_CrashAmount` | 冲击或破裂分支强度；具体空间遮罩和响应随材质组而异。 |
| `_RippleAmount` | 让底图呈现径向波动。 配合 Ripple Beat 调整波纹相位或脉冲状态。 不要把 Ripple Beat 直接当作项目 BPM。 |
| `_FirstTransitionPhase` | 推进预设内置的分阶段开场变化。 Phase 选择该材质的过渡状态，可用关键帧推进。 这是特定材质的进度参数，不是通用透明度。 |
| `_RedAmount` | 推进该底图组的红色处理分支。 可与形变独立编排，具体颜色关系由材质决定。 |
| `_VerticalCorruptionAmount` | 在选定位置附近产生纵向损坏感。 位置与强度分开控制，使用纵向噪声和随位置变化的衰减。 |
| `_MuteAmount` | 控制底图的视觉抑制分支。 只作用画面，不会静音音频。 分支已确认，具体衰减形态尚未单独验收。 |
| `_HackerTransitionAmount` | 用分块阈值切换材质中的场景图层。 含量化、哈希和阈值抖动，可让过渡本身呈现图案。 依赖自带的 Special、Network 或 Cell 等辅助贴图。 |
| `_NetworkPhase` | 推进网络图层的程序状态。 与网络转场材质中的图层和取样路径联动。 不是通用时间或强度；具体动态图案尚未逐项验收。 |
| `_BlurCell` | 控制柔化的单元格图层。 与材质中的 Cell 资源和网络场景组合。 不是通用的多次采样模糊，依赖该组素材。 |
| `_BlurDistort` | 控制柔化场景中的采样扭曲。 用于该组场景的柔化与扰动组合。 具体形态尚未单独验收，先用小幅变化确认。 |
| `_BrightAmount` | 在暗版和亮版底图之间混合。 可让两张同构图图片中的不同细节逐渐显露。 依赖 BrightMap；换主背景图不会自动制作对应亮版。 |
| `_RipplePhase` | 推进底图波纹的相位状态。 可用单调或往返的关键帧改变波纹位置。 相位不是强度，也不是项目 BPM。 |
| `_ChugAmount` | 让四路空间遮罩分别发生局部脉冲。 XYZW 对应遮罩 RGBA，四路值和遮罩点乘后驱动局部变化。 四路遮罩不是四条游戏轨道。 |
| `_AltColorAmount` | 在该组预设的颜色状态间过渡。 可与局部脉冲独立编排，具体颜色由材质和素材决定。 |
| `_Hnoise` | 给底图加入横向噪声扰动。 作用在底图内部，可与其余兼容参数合并为一次背景绘制。 |
| `_Monochrome` | 推进该底图的单色化处理。 用于彩色与单色视觉状态之间的变化。 |
| `_EnterEffectZOffset` | 调整开场空间感变化的偏移项。 这是材质的输入参数。 具体投影形态待确认，不能据此宣称移动了游戏相机。 |
| `_NeuroAmount` | 控制 Neuro 程序图案分支的强度。 已核对该参数及程序路径。 具体动态形态尚未单独验收，不根据名称补写观感。 |
| `_AsanohaDisplaceAmount` | 以麻叶命名的程序化图案位移。 用格点、周期或分区数学组织底图取样变形。 已确认不是分别加载一张纹样贴图；该分支的完整动态形态未逐项验收。 |
| `_SeigaihaDisplaceAmount` | 以青海波命名的程序化图案位移。 用格点、周期或分区数学组织底图取样变形。 已确认不是分别加载一张纹样贴图；该分支的完整动态形态未逐项验收。 |
| `_KikkouDisplaceAmount` | 以龟甲命名的程序化图案位移。 用格点、周期或分区数学组织底图取样变形。 已确认不是分别加载一张纹样贴图；该分支的完整动态形态未逐项验收。 |
| `_ShippouDisplaceAmount` | 以七宝命名的程序化图案位移。 用格点、周期或分区数学组织底图取样变形。 已确认不是分别加载一张纹样贴图；该分支的完整动态形态未逐项验收。 |
| `_EgasumiDisplaceAmount` | 以霞命名的程序化图案位移。 用格点、周期或分区数学组织底图取样变形。 已确认不是分别加载一张纹样贴图；该分支的完整动态形态未逐项验收。 |
| `_UrokoDisplaceAmount` | 以鳞命名的程序化图案位移。 用格点、周期或分区数学组织底图取样变形。 已确认不是分别加载一张纹样贴图；该分支的完整动态形态未逐项验收。 |
| `_YagasuriDisplaceAmount` | 以矢絣命名的程序化图案位移。 用格点、周期或分区数学组织底图取样变形。 已确认不是分别加载一张纹样贴图；该分支的完整动态形态未逐项验收。 |
| `_TrackOpacity` | 轨道表面、边框与判定线的不透明度系数：0 隐藏，1 原样；支持连续关键帧。不会修改判定、输入或分数数据。 |
| `_ScoreOpacity` | 分数及其边框的不透明度系数：0 隐藏，1 原样；支持连续关键帧。不会修改判定、输入或分数数据。 |
| `_SongInfoOpacity` | 曲名、作者、封面与难度资料的不透明度系数：0 隐藏，1 原样；支持连续关键帧。不会修改判定、输入或分数数据。 |
| `_ClearStateOpacity` | 通关状态区域的不透明度系数：0 隐藏，1 原样；支持连续关键帧。不会修改判定、输入或分数数据。 |

## 上下文相关参数

- `_KW_*`：离散开关，-1 关闭、0 自动、1 开启。渐变用 Amount 或效果强度。
- `_VfxOpacity`：独立后处理混合输入和结果；底图控制项则插值参数，不额外增加图像混合 Pass。

### `custom/procedural-pulse`

- `_Frequency`：同心脉冲环的空间频率；越大环带越密。
- `_Speed`：脉冲相位随效果局部秒数推进的速度，不是 BPM。
- `_Color`：脉冲环的 RGB 颜色，模板不使用该颜色的 Alpha。

### `custom/wave-lines`

- `_Intensity`：全局效果强度；0 精确返回输入，1 为完整效果。
- `_CenterX`：波动和透视的中心横坐标，0 左、1 右。
- `_CenterY`：波动和透视的中心纵坐标，使用 Shader UV。
- `_WaveAmount`：径向 UV 位移幅度；0.01 为轻微波动，增大可看清建筑边缘弯曲。
- `_WavePhase`：波动相位，单位圈。线性关键帧产生传播，保持或反向关键帧可停住或逆行。
- `_WaveFrequency`：径向波纹疏密；不是 BPM 或播放速度。
- `_LineAmount`：六条程序曲线的发光强度；0 隐藏金线。
- `_LineColor`：线条 RGB 颜色；当前实现不使用 Alpha。
- `_LinePhase`：曲线扫动与摆动的相位，单位圈；与波动相位独立。
- `_LineWidth`：细亮芯宽度，使用按画面高度归一化的坐标；导数抗锯齿随分辨率适配。
- `_LineBend`：线条弯曲幅度；0 保留直线式构图。
- `_BaseDim`：背景压暗量；0 保持原亮度，便于单独凸显发光曲线。
- `_Collapse`：中心附近的径向取样变形，可做向远端收拢的视觉过渡；不移动背景元素对象。
- `_PortalRadius`：从中心扩张的软显露半径；与 Tunnel Visibility 一起使用，0 不显露网格。
- `_RushMix`：网格在显露区域中的可见度；0 跳过网格计算。
- `_RushColor`：三角网格与过渡边缘的 RGB 颜色；Alpha 未参与。
- `_Travel`：沿固定透视网格推进的路程。线性关键帧控制匀速，斜率改变对应加减速；负向斜率可倒行。
- `_GridWidth`：网格亮线宽度，使用程序网格坐标；不等于屏幕像素。

### `custom/perspective-cells`

- `_Intensity`：全局强度；0 精确旁路，1 完整应用。
- `_CenterX`：远点横坐标，0 左、1 右；金线、波动和推进共用。
- `_CenterY`：远点显示纵坐标，0 在上、1 在下；独立转换到纹理采样坐标。当前演示为0.18。
- `_WaveAmount`：径向位移幅度，0 关闭扭曲。
- `_WavePhase`：波动传播相位，单位圈；可以停住或反向。
- `_WaveFrequency`：波纹空间频率，不是BPM。
- `_LineAmount`：从上方远点延伸的光线亮度。
- `_LineColor`：光线RGB色彩；Alpha未使用。
- `_LinePhase`：不同纵深光线的摆动相位，不绕画面中心统一旋转。
- `_LineWidth`：光线宽度，随纵深缩小，使用按画面高度归一化的坐标。
- `_LineBend`：光线曲率，弯曲随接近观众而增强，远点仍收束。
- `_BaseDim`：输入底图压暗量，不改变骨架结构。
- `_BackgroundTint`：输入底图RGB乘色，白色保留原色，Alpha未使用。
- `_Collapse`：围绕上方远点的取样收拢强度。
- `_PortalRadius`：软显露半径，与结构可见度联合使用；从共用远点扩张。
- `_RushMix`：三角骨架可见度；0 跳过结构计算。
- `_RushColor`：实体肋和亮边的基础RGB色彩，Alpha未使用。
- `_Travel`：累计推进路程；斜率决定速度，改变斜率可连续加减速。
- `_GridWidth`：线段距离场的实体阈值，增大会变粗；不等于像素宽度。
- `_GridScale`：纵深方向的结构密度；环周保持10个周期。
- `_CellRandomness`：三角顶点位置的不规则程度，不是逐帧随机噪声。
- `_Reflection`：复用输入底图的风格化反射量，不是物理环境反射。
