# 材质组合预设

组号是编辑器内部资源身份。BG 与 PP 分开，不能把组号理解为美术风格规定。

| 组 | 底图组合 | 后处理组合 |
| --- | --- | --- |
| `01` | 径向流动与单元格遮罩的组合。 | 冲击破裂与边缘乘色的组合。 |
| `02` | Aura、分段横移和布局种子的组合。 | 分块故障、破裂与边缘乘色的组合。 |
| `03` | 分阶段开场、三角错位、连续流场和冲击的组合。 | 扭曲、缩放色差、冲击和故障分支的组合。 |
| `04` | 径向流动、三角错位、波纹、冲击和横向噪声的组合。 | 缩放色差、分块故障与破裂的组合。 |
| `05` | 七种命名纹样位移与流场、冲击的组合。 | 信号失常、破裂与边缘乘色的组合。 |
| `06` | 可定位的纵向损坏、流场、红色和视觉抑制的组合。 | 数字故障、破裂与边缘乘色的组合。 |
| `07` | 网络图层、分块转场与柔化单元格的组合。 | 扫描线、模糊故障与破裂的组合。 |
| `08` | 暗/亮双图混合、流场与波纹相位的组合。 | 冲击破裂与边缘乘色的组合。 |
| `09` | 连续流场、同帧嵌套变换、缩放色差和切片的组合。 | 数字故障、破裂与边缘乘色的组合。 |
| `10` | RGBA 四路局部脉冲、径向流动和颜色变化的组合。 | 分块故障、破裂与边缘乘色的组合。 |
| `11` | 单色化、流场、三角位移与开场图案分支的组合。 | 不规则变形、缩放、水平噪声和故障分支的组合。 |
| `12` | 另一种径向流动、单元格遮罩和冲击组合。 | 缩放色差、破裂与边缘乘色的组合。 |

底图控制项使用 `BackgroundSource` 选择实际材质组。同组参数可合并；跨组重叠时当前采用时间轴下方组。
组内也可能有编译变体互斥，不应向用户承诺任意组合都可同时启用。详见[渲染约定](../RENDERING.md)。
