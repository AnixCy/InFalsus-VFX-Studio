# 效果时间轴

版本 0.7.4。启动后点击“演出视图”，通过“制谱视图”返回。两种视图分别编辑，演出视图不处理 Note 编辑输入。

## 基本流程

1. 加载音频或背景图片；无需打开谱面，没有音频也可使用静音时间轴。
2. 从效果库拖到时间轴创建效果片段，也可双击条目或点击 +。新片段默认 5 秒，并定位到起点方便预览。
3. 在右侧检查器选择参数，调节数值或点击 ◆ 打帧。默认仅显示 Base Color 和曝光，其余参数在打帧后进入可见轨道。
4. 拖动片段、关键帧或片段右边缘调整时间；手动保存 .vfx.json。

谱面视图已加载音乐时，演出视图直接复用同一音频和时钟；切换视图先暂停，再点播放继续。画面上方显示当前音乐名称或“静音时间轴”。音频结束后停在对应谱面时刻，再次播放从头开始；音频偏移在完成时刻计算中仅应用一次。

效果库“全部 / 效果 / 预设 / 自定义”只筛选可添加的效果，所有实例和参数始终共用一条时间轴。未打帧的参数仍保留其材质默认数值，不占可见轨道。

## 实例与参数

- 后处理可重复添加、叠加和分别启停。上方轨道先合成，右侧 ↑ / ↓ 调整顺序。
- 点击效果行选择实例；左侧箭头收起/展开其动画参数，圆点切换启停。检查器可改名称、区间或删除。
- 从背景页点选效果轨道时自动显示效果检查器；切换效果先应用原数值草稿，无效输入保留原选择并提示。选择另一个效果时检查器回到顶部，轨道原有收起状态保留。
- 拖动片段同步移动其关键帧，稳定身份保留；拖右边缘只改结束时刻，裁掉的动画数据保留。
- 检查器结束留空表示持续；新片段默认有限时长。旧工程的效果保留原持续范围。
- 后处理“混合强度”将该效果输出与它之前的图像混合，可单独打帧；0 为旁路，1 为完整效果。
- “背景”页只管理图片导入与清除；材质效果从效果库添加，右侧显示所选效果参数。
- 移除参数动画保留参数默认值。删除实例同时移除其动画；均可撤销。
- 首次连续动画从效果区间起点建立默认值帧，避免到首个目标才突变。新增帧限制在当前片段范围内；旧工程可显式“补齐起点”，不自动写盘。

缓动作用于所选关键帧到下一帧的区间：线性、平滑、保持、正弦、三次、回弹。颜色/向量各分量共享时间和缓动。Shader 开关属于离散状态，渐变使用 Amount 或混合强度；故障、采样等算法的感知效果未必线性。

## 图片与底图效果

“背景”仅选择或清除图片。流场、嵌套旋转等从效果库拖入，Ephemeral / 流场扭曲与 Feedback / 嵌套缩放旋转在顶部，也可搜索名称。每个控制项有自己的区间、启停和关键帧，同一兼容组在背景材质内合并，不增加逐项后处理 Pass。不同原始组重叠、或互斥模式冲突时显示提示，以下方控制为准。范围与融合计划见 [渲染说明](RENDERING.md)。

## 曲线与轨道高度

悬停参数行底部分隔线时整条高亮并显示上下拖动光标；命中区覆盖边界上下两侧。拖分隔线调整高度，双击恢复默认；Esc/失焦取消，高度保存在当前安装布局，不写入运行数据。关键帧按实际数值纵向排列，拖菱形同时修改时刻和数值。

选中关键帧后，其到下一帧的过渡显示两个紫色 Bezier 控制柄；拖动调整起步、收尾或超调，也可先点检查器“贝塞尔”。一次拖动一次撤销。等值端点保持水平，需要中间关键帧才能产生幅度变化。颜色/向量可切换 RGBA/XYZW 观察，缓动由分量共用。

控制柄采样为既有 Curve 格式，保存后仍可恢复编辑，没有新增运行时格式。自定义折线或既有缓动首次拖柄时转换为三次曲线。

## 操作

| 操作 | 方式 |
| --- | --- |
| 定位 | 点击刻度或轨道空白；拖标尺连续定位，松开保持暂停，Esc/失焦返回拖动前时刻 |
| 新增关键帧 | 右侧 ◆，或双击已有参数轨道 |
| 精确修改 | 检查器时间/数值输入；Enter 应用，Esc 取消草稿 |
| 移动 | 拖片段或菱形；一次拖动一次撤销，Esc 取消 |
| 删除 | Delete；优先删除所选帧，其次参数动画或所选后处理实例 |
| 播放/暂停 | 顶部按钮；默认 Q |
| 按住预览 | 默认 Space，松开返回；失焦停止 |
| 保存、另存、打开 | 默认 Ctrl+S、Ctrl+Shift+S、Ctrl+O |
| 撤销/重做 | 默认 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z |
| 缩放时间轴 | + / − 或 Ctrl+滚轮 |
| 平移 / 轨道滚动 | Shift+滚轮 / 普通滚轮 |
| 跟随 | 将播放头移回可见范围 |

快捷键共用制谱视图“设置 → 操作 → 热键”的当前映射。数值/名称输入保留文本编辑按键。关闭未保存工程使用单个非阻塞确认，取消保存或失败不退出。

## 效果与自定义

效果库包含色彩与曝光、画面变换、色散、径向波动、扫描线、噪声、像素化、暗角、淡出、遮罩与环形光效。“预设”保留 12 套原始材质组合，名称描述技术构成，不复制原谱完整事件编排。另外拆出 Screen Fracture、Block Glitch、Chromatic Zoom、UV Warp、Digital Glitch、Signal Scanlines、Blur Glitch、Warp Zoom、Horizontal Noise、Chaos Distortion 与 Signal Malfunction。

“自定义”可创建/打开 Shader 效果，编辑代码保存后自动更新；Properties 直接生成参数和打帧入口。手动构建与资源导入位于高级选项。程序化绘制可使用图像、UV、全局时间、片段局部时间和可动画参数；示例与作者构建入口见 [CUSTOM_EFFECTS.md](CUSTOM_EFFECTS.md)。

未启用或区间外的效果不执行 GPU Pass；首次使用时加载材质，同 Bundle 的重复实例共享资源包并拥有独立材质。画布和中间目标复用。实际全尺寸帧时间仍待测量，不承诺未测的 FPS。

## 工程与兼容

工程与 SPC 分开，音频/图片按路径引用，不复制整曲。旧背景/参数工程仍可读取，所有旧动画显示在统一视图中，不改原文件；资源根目录重新绑定当前预览安装，便于继续添加自定义效果并保存。

实例元数据、顺序、区间、启停和关键帧写入独立工程。新实例使用 effect.instances 能力声明，旧运行端会拒绝，而非静默忽略时间区间。当前游戏适配器尚未迁入，本版不是游戏演出包导出器。

官谱资源仅在本地缓存，不纳入 Git。仍可用只读准备脚本：

~~~powershell
python scripts/Prepare-OfficialEffects.py --game '<游戏目录>' --survey '<survey.json>' --output '<新目录>/Effects'
~~~

把生成的 Effects 放在 local/build/preview；副本生成脚本一并复制，约 22 MB，无音频。预览使用 Linear 管线，不宣称与游戏全部色彩设置一致。

拖动时显示跟随卡片、插入位置及实时起止时间；Esc 取消。常用尺寸按可用空间限制 UI 缩放，列表与检查器滚动，长名称省略。

Space 与 Q 已经通过真实窗口键盘测试；视觉、物理鼠标拖放、音频试听及完整视频导出尚待人工验收，自动验证范围见 [VALIDATION.md](VALIDATION.md)。
