# 演出视图与关键帧

版本 0.2.1。启动测试副本后点击右上方“演出视图”，左上“制谱视图”返回。

## 独立编辑

进入前提交已有谱面字段并取消未完成的拖动，暂停原播放、停止击打音效，关闭谱面相机、GUI 与编辑输入。演出视图使用独立背景平面、隔离相机和后处理画布，没有轨道、Note 或游戏 HUD。返回时恢复原相机与制谱流程，演出快捷键不会同时传给制谱。

可直接选择本地 WAV/OGG/MP3、背景 PNG/JPEG，无需打开谱面。没有音频也能使用静音时间轴。音频复用宿主加载器与 transport，Shader 和 SV 不自行累计播放时间。

## 操作

| 操作 | 方式 |
| --- | --- |
| 选择参数组 | 左侧“背景 / 后处理 / 通用” |
| 定位 | 点击刻度或轨道空白处 |
| 添加关键帧 | 双击轨道，或右侧“◆ 添加/定位” |
| 选择关键帧 | 点击菱形，播放头同时定位 |
| 移动关键帧 | 拖动菱形；右侧也可输入精确秒数，回车应用 |
| 修改数值 | 右侧滑杆或数值框；颜色/向量分量分别显示 |
| 自动关键帧 | 默认开启；调整时在播放头建帧，已选中的关键帧优先被编辑 |
| 删除 | 右侧删除或 Delete；清空轨道可一次撤销 |
| 播放/暂停 | 顶部按钮或默认 Q；输入数值时不触发 |
| 按住预览 | 默认 Space；松开返回开始位置，失焦安全停止 |
| 打开、保存、另存 | 默认 Ctrl+O、Ctrl+S、Ctrl+Shift+S |
| 撤销、重做 | 默认 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z；数值输入期间保留文本撤销 |
| 取消拖动/输入 | Esc；退出确认中的 Esc 取消退出 |
| 时间轴缩放 | `+ / −` 或 Ctrl+滚轮，以指针为中心 |
| 时间轴平移 | Shift+滚轮；“跟随”将播放头移入可见范围 |
| 参数轨道滚动 | 时间轴上的普通滚轮 |

快捷键直接共用制谱视图“设置 → 操作 → 热键”的当前映射，修改后立即生效，旧物理按键随之停用。演出视图只处理已有演出操作，不执行 Note 放置、镜像等制谱命令。

所选参数附有插值曲线。一次拖动对应一次撤销，取消恢复原数据，同一参数不允许两个完全相同的关键帧时间。

首关键帧前使用默认值，末关键帧后保持终值。缓动属于选中关键帧到下一帧的区间：线性、平滑、保持、正弦、三次、回弹。颜色和向量共享一条轨道，各分量单独修改。

连续参数首次在非零时刻建帧时，自动添加 0 秒默认值起点，避免到目标帧才突然改变。两个新帧作为一次编辑撤销；如需延后渐变开始，可移动起点。旧工程保留原语义：检测到缺少起点时，时间轴显示“补齐起点”，一次补齐非保持型连续动画，可撤销，手动保存才写入。

## 效果目录

- 通用背景：亮度、颜色、UV 位移、空间/时间频率、水平/垂直偏移、内置图案混合。
- 官谱材质：12 个通用编号，每套含原始背景与后处理 Shader，共 24 个材质。标签显示主要技术关键词，不含真实曲名。辅助纹理和原材质一起准备，可替换背景底图。
- 通用调整：曝光、对比度、饱和度、缩放、旋转、径向色散、波动频率/速度、扫描线、噪声、像素化、暗角、淡出、径向遮罩、光环半径/宽度/强度。

官谱开关有“自动 / 关闭 / 开启”：自动根据相关强度启用，关闭可压过非零强度。开关属于离散状态，新增开关帧使用保持缓动，面板不显示连续缓动选项。渐变需编排对应 Amount 强度参数。故障、采样、闪烁等 Shader 内部算法本身可能不连续，参数线性不保证画面感知线性；未逐一验收全部关键词组合和极端参数的视觉效果。

当前图含一个背景、一个可选官谱后处理和通用调整，按顺序合成。更换材质保留公共参数及关键帧，不匹配的参数可撤销恢复。通用调整轨道独立保留。暂不提供任意效果堆叠或节点排序。

## 工程与资源

工程继续使用 `.vfx.json`，保存关键帧身份、数值、缓动、材质图和媒体路径，兼容早期单背景工程。音频/图片按路径引用，不复制整曲或改写 SPC。移动媒体后需保持路径可用，原材质缓存需在对应测试安装中存在。

官谱部分是原始编译 Shader/材质，不是 HLSL 近似重写，也没有复制原谱事件编排。缓存只在本地准备，不纳入 Git。Studio 预览为 Linear 管线，不宣称等同原游戏全部色彩与后处理设置。新增通用 Shader 为本项目实现，与官谱来源分开记录。

## 本地准备官谱资源

只有构建者需要 Python/UnityPy；已生成的测试副本不需要它们，也不需要启动游戏。

```powershell
python scripts/Prepare-OfficialEffects.py `
    --game '<已有游戏目录>' `
    --survey '<已核对的资源 survey.json>' `
    --output '<新的构建输出目录>/Effects'
```

脚本核对研究清单中的来源哈希，只读取原安装。移除剧情脚本和非渲染对象，保留 Shader、Material、Texture 原始数据并重建索引。输出 effects.json、12 个 Bundle 和来源哈希记录，约 22 MB，不含歌曲音频。输出目录必须不存在。

把生成的 Effects 放在 local/build/preview 下，副本生成脚本会一并复制。没有缓存时仍可使用通用背景和通用调整。

视觉、实际操作和音频试听由人工验收。自动检查范围见 [VALIDATION.md](VALIDATION.md)。当前没有游戏包导出或游戏内部署。
